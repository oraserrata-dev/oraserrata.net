Rouse Relay

A small open-source server that receives wake requests from Rouse and sends the Wake-on-LAN packet on your local network, so you can wake a machine while you are away from it. Builds for macOS, Windows, Linux, and Docker. If you already keep a Mac running, Rouse itself can do this job instead.

Which one do I need?

Rouse alone is enough to wake devices while you are on the same network as them. Rouse Relay is the extra piece that lets you wake them while you are somewhere else, and it only needs to be installed once, on a machine at the location you want to wake into.

For help setting either up, see Support or the step-by-step Enable Wake-on-LAN on Windows guide.
