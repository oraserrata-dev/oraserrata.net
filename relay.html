Rouse Relay

A lightweight server that receives wake requests from the Rouse app and broadcasts Wake-on-LAN packets on your local network. Install it on any always-on device.

Already have a Mac that stays on?

You may not need the standalone server at all. Download Rouse from the Mac App Store on that Mac, open Settings, and turn on Relay Mode. Rouse then shows you the handful of values to enter on the devices you wake from. That Mac becomes the relay, with no separate server to install or keep updated.

The standalone server below is for everything else: a Mac with no Apple ID signed in, and therefore no access to the App Store; a Raspberry Pi, NAS, or home server; a Windows or Linux machine; or simply a preference for one small program over the full app or a Docker container. It is open source and does one job.

Docker

For Synology, QNAP, Raspberry Pi, or any Docker host.

Docker Compose
services:
  rouse-relay:
    image: oraserrata/rouse-relay:latest
    container_name: rouse-relay
    restart: unless-stopped
    network_mode: host
    environment:
      - AUTH_TOKEN=your-password-here
Docker CLI
docker run -d \
    --name rouse-relay \
    --network host \
    --restart unless-stopped \
    -e AUTH_TOKEN=your-password-here \
    oraserrata/rouse-relay:latest

Replace your-password-here with a token generated in Rouse's relay settings. The relay refuses to start with the placeholder.

How it works

The relay sits between the Rouse app and your sleeping devices.

  1. 01

    Install the relay

    Unzip the download on any always-on device, open the install script, and set AUTH_TOKEN to a token you generate in Rouse. The installer refuses to run with the placeholder.

  2. 02

    Connect via VPN

    Set up Tailscale, WireGuard, or OpenVPN so you can reach your home network when you're away.

  3. 03

    Configure Rouse

    In Rouse, edit your home Location, enter the relay's address and your token under Remote relay, then use Test Connection to verify.

Requirements

Always-on device
The relay needs to run on a device that stays powered on and connected to the same network as the devices you want to wake.
VPN for remote access
To wake devices when you're away from home, you need a VPN that connects you to your home network. Tailscale is the easiest option.
Rouse app
Available on the App Store for iPhone, iPad, and Mac. The relay works with Rouse v1.0 and later.
